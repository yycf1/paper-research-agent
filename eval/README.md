# 公开评测资料

当前题目和回放使用原创合成资料。`evidence_cases.json` 可配合 `examples/offline-evidence/corpus.json` 无密钥运行。`evalset.json` 是旧章节级评测器的格式示例，在线执行需要自己准备与 ID 匹配的索引。`agent_tasks.json` 是工具任务格式示例；`agent_demos.json` 是明确标记的隔离资料真实调用回放。

历史私人开发集和逐条摘录已从当前版本撤下；`docs/retrieval_benchmark.json` 仅保留聚合历史指标，与新的合成题目无对应关系。新评测文件和运行输出请保存在忽略的 `data/`，检查后再选择公开。

# 2026-10-15 用户验收修复记录

依据《项目一用户验收报告》，优先修复获得全文、失败恢复和状态一致性。所有下载、导入、删除、索引与浏览器验证均使用隔离库；私人文献未进行批量处理或修改。

## 下载流程

- 文献库新增批量“仅下载所选全文”，阅读页新增单篇下载；均只处理明确选择的 ID，不自动分析。
- 重复候选允许勾选补全文。入库层按 DOI/归一化标题解析原 ID、合并候选链接，防止跨源另建记录及下载到错误 ID。
- 新增给原记录上传全文，保留原题录和分组。更换现有全文须明确确认，并清理旧解析、知识、复核及索引，回到下载完成阶段。
- 导入即检查格式可解析性；拒绝损坏、密码保护、零页面与全空白 PDF。扫描件仍可保存，但当前解析器不提供 OCR，文字不足时提示换用含文本的文件。
- 已有文件校验后才跳过；损坏的缓存可以重新下载。网络、授权、拒绝、限流、非 PDF、损坏内容及本地写入失败保留可执行提示和来源尝试记录。
- 初始链接、论文落地页、DOI 落地页及同 Work/DOI 开放副本回退共用有界请求预算。OpenAlex 三条访问路径均支持 OPENALEX_API_KEY，错误信息不携带 Key。
- 普通任务与逐篇结果存入 jobs.db，重启后回看；未结束任务标为已中断。仅重试失败/无链接/未完成项，已经成功保存的项目不重新请求。

## 其他验收缺陷

- 删除先原子保存待清理记录并移除题录；清理失败返回 HTTP 202、ok=false 与明确待清理原因。检索在两条召回分支及版本校验之前排除这些记录，防止一篇残留索引拖垮全库问答。任务页提供重试清理。
- 研究助手进入页面时刷新论文选择器；文献库列表使用请求版本丢弃过期响应，删除/重命名当前分组后不再重复提交旧筛选请求。分组路由支持中文、空格和斜线。
- 原文访问限制在该记录的受管目录。阅读页、字段依据及单篇问答可打开原 PDF，对可用页码使用 #page=N；DOCX 明确无稳定页码。
- 人工字段复核可保存支持/不支持/冲突/不适用及备注，绑定事实与证据版本；旧版本提交被拒绝，源内容变化后旧结论不再沿用。
- Agent 统计返回明确作用范围，最终结果附所选论文范围说明。复现方案加强事实/未知/建议约束，对本次观察到的无依据“未公开”断言至多修复一次，失败不覆盖旧方案；这不是通用语义真实性证明。
- 阅读页代码工作区和运行记录收进“高级实验”。仍使用本机进程，未新增系统隔离或宣称自动完成真实科研训练。

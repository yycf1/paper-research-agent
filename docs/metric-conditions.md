# 指标与实验条件

指标抽取保留完整名称（含 @K）、数值、模型/基线归属、任务、数据集、划分、定义、单位与评估协议；没有对应原文就留空，不能把不同表格的条件拼接。字段证据保留这些条件参与当前事实摘要，旧复核不会自动确认新增条件。

`compare_papers.comparability` 在已展示的指标中逐对检查明确记录的条件，返回条件不同、条件缺失、尚未复核或已复核的同条件候选，并给出具体缺项/差异。保留论文 ID；每对论文至多展示四组指标检查，其余数量明确登记。检查结果随 Agent 步骤和历史保存。

Recall@10/Recall@20、比例/百分比、不同测试划分或采样协议会显示差异，不做自动换算或猜测。相同字符串、有效引用，甚至已复核的部分字段都不能自动排除未记录的混杂因素；`ranking_allowed` 保持 false。此功能帮助判断还需要核对什么，不生成伪造的可比实验结论。

离线测试 `tests/test_comparison_conditions.py` 覆盖参数、数据集、划分、单位、协议差异、条件缺失、复核状态与输出预算。

Web 可用 `POST /api/compare`，参数为 `topic`、2–6 个不同的 `paper_ids` 及可选 `k_per_paper`。它复用同一个带范围执行器返回证据与条件检查，不额外调用答案生成模型；实际语义召回仍可能调用嵌入/重排服务。

# 2026-10-16 Agent 验收、观测和 Web 完善记录

已实现结果验收、统一调用台账、真实模型成功/失败演示回放及电脑端 Web 展示。此前下载可靠性修复继续保留；本轮没有批量下载或处理个人文献。

## 行为变化

- 评测与页面区分执行结束、条件通过、失败/部分完成、待核验。fatal 工具和关键词“完成”不能作为目标成功的凭据。
- 入库检查真实账本新增及步骤确认 ID；证据回答重新核对来源与引用编号；只读检查前后文献行指纹。
- 对话、向量化、重排、内部 QA、重试、收尾总结统一归属任务，阶段/模型/耗时可查；未知用量与费用如实保留。普通问答也展示台账。
- 历史 JSONL 回读保留验收、结构化证据和调用明细，中断时已完成请求仍可回查。没有自动恢复执行。
- Web 增加验收选择、概览、时间线、证据、回放与导出；参数折叠。执行结束但未通过验收的记录不用成功颜色；重排用量未知不显示为零费用。

## 使用入口和限制

“研究助手 → 执行任务”可选择验收方式；“任务记录 → 研究任务演示回放”可直接浏览现成记录，回放不调用模型。全部条件与用量口径见 [详细说明](agent-outcomes-and-usage.md)。

验收仅覆盖所选条件。引用结构通过不等于语义正确，尤其没有自动核验最终 Agent 总结的全部事实。库快照受并发写入影响，应在隔离库评测。token 预算是下一轮决策前的软限制；工具内部调用、最后总结和用量缺失均可能使它低于实际费用。

个人专业技能独立于项目使用范围，本轮没有修改简历。实际项目同步采用逐文件基线与备份；个人数据、密钥、用户 Python 版本设置及其它未提交改动不属于同步范围。

# 附录与长文覆盖

PDF 解析跳过参考文献区域，遇到明确的 Appendix、Supplementary Material 等附录标题后恢复读取，包含同页与后续页。保留原页码锚点；最多处理 60 页，并在 `parse-coverage` 注释中登记总页数、已处理页数、截断及附录恢复情况。规则仍为启发式，双栏、公式、表格和扫描版不保证完整恢复。

结构抽取和精读报告使用同一分段计划：每段最多 36,000 字符，最多 4 段。预算内覆盖全部解析文本；超预算优先开头、末尾及实验/结果/附录所在窗口，并明确记录未覆盖的字符区间。覆盖状态指送入模型的文本范围，不能证明模型无遗漏、语义正确或 PDF 完整。

短文保持原来一次生成的路径。长文结构逐段提取，合并列表和互补字段；冲突保留首个候选、降低置信度并登记说明，所有分段候选及其范围保留，不凭空选择更好的数字。报告先生成带范围笔记，再综合；保留输入覆盖提示和机器可读记录。部分段落或 PDF 页数超预算时，明确显示部分覆盖。

正常长文最多 4 次结构提取、4 次分段笔记及 1 次报告综合；原有无效 JSON/空报告重试仍各自至多一次。较短输入不增加分段调用。用量累计返回，当前是字符和次数预算，不能作为绝对费用上限。

解析产物 manifest 绑定原文件内容摘要与解析契约/页数上限；原文件变化或契约变化后单篇/批处理重新解析，之后重建知识与索引。CLI 显式 parse 使用相同登记方式。旧抽取/报告契约升级后不复用前缀截断产物。

测试入口 `tests/test_document_coverage.py`：真实原创 PDF 的后置/同页附录、页数上限、40,000 字符后事实进入两条链、分段冲突、预算遗漏区间、原文件变化和空输入。模型由脚本替代，不据此报告真实论文的抽取准确率。

# 统一研究对话

单次提问与连续追问的区别是是否使用历史语境；比较是针对多篇资料的一种研究请求。三者共用对话、论文范围和证据展示。执行操作则会调用工具改变资料或生成文件，保留显式提交与原有确认门。

## 使用

1. 打开研究助手，选择整个文献库或指定 1–6 篇论文，直接提问。首条消息自动创建会话，后续问题沿用范围和最近语境。
2. 需要结构化比较时，在“本次操作”选择“比较论文”，选 2–6 篇并发送。比较显示研究目标、数据集、指标候选和条件缺项；发送后自动回到提问，便于继续追问。
3. 需要检索入库或生成方案等多步操作时，选择“执行操作”，输入目标并点击“提交执行”。任务卡、工具步骤、验收结果和确认按钮在当前会话里显示。
4. 左侧恢复历史；“新对话”清空上下文和范围。输入框支持 Enter 发送、Shift + Enter 换行，中文输入法候选确认不发送。跨页带入与示例均不会自动运行。

## 数据与边界

- `/chat` 默认 `action=chat`，显式 `compare` 使用原比较执行器；普通消息不会转为 Agent。论文详情原 `/ask` 与 `/compare` API 保留兼容。
- `paper_ids` 省略时继承会话范围，显式 `null` 切回全库；空数组、无效或已删除 ID 拒绝，不能静默扩大到全库。
- 范围由服务端校验，分类、题录统计、方向推荐、全文检索均受约束。同范围最近三轮用于指代；切换范围时不使用其它范围的历史答案供给新回答。所有消息仍可在界面回看。
- SQLite 会话表增加可空的范围列，消息增加 JSON 结构化结果列，旧库自动补列；原文献表不变。比较、出处、回答状态与调用台账随消息保存。
- Agent 显式关联 `session_id`，存储任务引用。刷新从注册表或轨迹读取实际进度，后续问题可获得最新结果。工具白名单、宿主范围、确认门不因历史语境而扩大；不自动恢复中断任务。
- 模型识别、答案质量与证据覆盖仍受模型和索引影响。当前比较为字段候选与原文依据，并未增加通用语义判定模型；未索引论文不能作为全文答案来源。
- 一个页面追踪一个运行任务的实时连接；切换会话仍保留连接，历史响应按请求版本检查，避免覆盖新视图。执行记录保留独立回看入口，“任务记录”仍用于集中审计与导出。

## 验证

`tests/test_unified_assistant.py` 的 13 项检查覆盖范围继承/重置、比较持久化与追问、失效范围拒绝、显式任务关联、历史语境与工具范围，以及方向推荐范围；`tests/test_chatstore.py` 另覆盖旧数据迁移。完整 Python 回归 440 项通过（156.75 秒），前端 build/lint 通过，保留 3 条 effect 提示。

`scripts/verify-web.cjs` 的 50 项原创合成 API 响应检查覆盖 1440/1280 的统一页面、任务确认和原有文献/下载流程。隔离真实后端的浏览器检查另有 10 项，两种宽度均无脚本错误。

另在隔离 SQLite、Chroma 与真实后台 Agent 上注入脚本化模型，检查问答→追问→比较→刷新→显式执行→刷新→拒绝→追问的完整链路；没有线上模型请求，也未改动私人文献。这些检查不代表真实模型语义准确率。

# 五分钟演示

先按[使用指南](usage.md)启动。真实问答与处理需要模型密钥和额度；离线体验只演示检索证据链，不生成模型答案。

## 无密钥演示

运行 README 的 `eval-evidence --snapshot` 命令，打开生成的 Markdown 与 JSON。

展示问题、候选块、语料版本、失败阶段与尚未复核的答案状态。样例文本为原创合成内容，不称为真实论文评测或准确率。

## 已有文献的演示

1. **文献与处理（约一分钟）：** 打开一篇已处理论文，展示摘要、报告、阶段状态；说明新库需先导入并处理自己的文件。
2. **单篇问答（约一分钟）：** 问“本文使用哪些数据集？”，展开来源，检查答案中的名称是否由原文支持。
3. **多轮问答（约一分钟）：** 追问“它用哪些评价指标？”，说明查询改写用于处理指代，最终回答仍依据检索片段。
4. **字段比较（约一分钟）：** 在文献库勾选两篇，进入“比较所选论文”，输入研究主题，展示字段依据、待核对状态及实验条件差异；若需多步任务，再切换 Agent 任务并明确论文范围。
5. **失败边界（约一分钟）：** 问一个论文未报告的字段，展示证据不足；说明缺少候选不等于原文没有。遇到源站限流时展示真实降级信息，不伪造在线成功结果。

## 展示时应解释的取舍

- RRF 融合互补候选，但不保证所有指标改善；重排不能找回未召回的证据。
- 原始字段值与候选摘录同时可见，编号合法也可能不支持对应结论。
- 数据集、划分、任务、单位未核对时，不比较裸值大小。
- 轨迹能回看执行过程；阶段续跑与框架 checkpoint 恢复是不同能力。
- 复现执行属于扩展功能，当前只提供本机工作区与超时，尚无容器隔离。

当前电脑端截图见 README；[本轮界面验收记录](web-workspace-validation.json)使用原创离线响应检查交互。[历史字段界面验收](field_evidence_ui_validation.json)保留原验证条件，不作为新版界面的验收结果。

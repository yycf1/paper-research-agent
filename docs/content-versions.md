# 资料与产物版本

实验结构与报告旁保存 `.manifest.json`，绑定解析文本摘要、模型端点/名称、生成契约和产物摘要；文件存在或 mtime 更新不再等于可复用。密钥不参与摘要，不写入 manifest。CLI、批处理与单篇处理写入相同版本格式；历史无版本产物在下一次处理时重建。

索引块登记源文本摘要、嵌入配置摘要、分块契约与实际块集合指纹、预期块数。处理、CLI 与批量索引只有在全部块匹配时才跳过；空块不会被登记为新版本完成。已索引论文也进入增量检查。嵌入调用显式接收本次配置。

向量写入先校验数量、维度与元数据归属，再保存旧块，覆盖新块并删除多余尾块；失败时恢复旧块。同一路径的本进程读写共享锁，避免读到回滚中的块。若回滚也失败，会明确报错，不能声明新版本完成；这不提供跨进程事务，也不能保证突然断电时的应用级回滚。

问答检查已登记的源文本和嵌入版本，不把已更新文档的旧块继续送进生成。未登记版本的历史索引有明确提示，不能验证其新旧，建议重建。切换嵌入模型后须重新索引所有要使用的论文；向量维度变化需配置新的向量目录，当前不自动迁移 Chroma 集合维度。

详情 API 返回 `index_state`（ready/stale/legacy/unindexed/unknown、块数和 can_ask）与 `knowledge_current`。过期或未登记的抽取产物不会沿用旧人工复核。重新索引不等于重新分析，知识过期时保持 parsed，不能假装分析完成。

离线回归见 `tests/test_content_versions.py`：相同 mtime 的内容变更、配置/契约变更、部分写入失败后的真实 Chroma 回滚、坏向量、旧全文重建、只跳过当前版本、嵌入故障以及阻止旧证据生成。只使用手写向量和脚本化提取，不调用线上模型。

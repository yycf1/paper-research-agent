# 保存所选论文并下载全文

“仅文献信息”表示文献账本中存在标题、作者、摘要、DOI 等题录，尚未取得本地全文。学术索引提供的题录与出版社/仓库提供的全文是两项资源；题录可被检索不等于 PDF 可以直接请求成功。

发现页的主操作是“保存并下载全文”：先保存明确勾选的信息，再提交 `download_papers` 后台任务。副操作“仅保存信息”不提交下载。API 为 `POST /api/papers/ingest`，请求增加 `download_fulltext`；省略时为 `false` 以兼容旧调用，Web 主操作显式发送 `true`，响应可带 `download_job`。

工作线程使用独立账本连接，只遍历本次提交的唯一论文 ID，不按引用数补下载其他库内论文，不受旧批处理的全库回填逻辑影响。已有本地文件跳过重复下载；无链接保留题录；来源拒绝或网络失败保留题录与原因；成功更新本地路径与下载状态。不会自动解析、调用模型生成报告、写向量索引或改变已有分析阶段。

发现页与任务记录共用逐篇进度，包括等待、下载中、已保存、本地已有、无链接、失败、记录移除。执行结束不表示每篇下载成功。进度属于本次服务的内存任务记录，完成的文件与账本状态持久保留；重启不自动续跑未完成队列。

旧后端若忽略新增参数且不返回下载任务，前端显示“信息已保存，但未提交下载”，避免误报已排队。下载仍受来源可访问性限制，用户可保留题录稍后补文件。

验证包括：服务层只处理勾选范围/去重、已有文件不降级、失败与无链接区分、缺失记录不复活；API 明确选择保存或下载，并用本地真实 HTTP 服务提供原创 PDF，经过真实下载器、后台任务、账本更新后重新读取 PDF 文本。浏览器采用原创响应，检查默认组合操作、仅保存信息、部分下载结果、任务回读与旧后端提示。没有对个人库发起自动下载或调用真实模型。

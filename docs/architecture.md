# 架构与实现入口

项目有两类控制流：LangGraph 编排文献处理阶段；Function Calling 循环根据任务和工具反馈决定后续动作。两者复用 services 和本地数据，不把模型提出的调用直接当成程序已执行。

## 模块职责

| 入口 | 关键实现 | 职责 |
| --- | --- | --- |
| CLI | `src/paper_agent/cli/` | 参数解析与输出，调用共享服务 |
| Web API | `server/app.py`、`server/routes.py` | REST API、前端托管、任务入口 |
| MCP | `mcp_server.py` | 从同一工具注册表暴露能力与确认交互 |
| Agent | `agent/loop.py`、`agent/executor.py`、`tools.py` | 决策循环、执行工具、校验参数、回填反馈 |
| 文献处理 | `services/process.py`、`graph/pipeline.py` | 下载、解析、提取、报告与索引 |
| 检索问答 | `rag/qa.py`、`hybrid.py`、`reranker.py` | 查询改写、召回、融合、重排、证据回答 |
| 字段证据 | `extraction/evidence.py`、`services/facts.py` | 读取已有事实、候选定位、版本/摘录校验 |
| 诊断 | `rag/diagnostics.py`、`cli/diagnostics.py` | 标签与语料版本、逐阶段 trace、复核产物绑定 |
| 持久化 | `library.py`、`chatstore.py`、`server/agent_jobs.py` | 文献账本、对话会话、任务状态与轨迹回读 |

表内 Python 路径除注明外均相对 `src/paper_agent/`。

## Agent：提出调用、执行、回填

模型看到工具定义后返回调用名称和 JSON 参数。执行器实际运行工具，结果以 `role=tool` 和对应 `tool_call_id` 回填；模型继续决定换参数、用下一工具或停止回答。

工具状态包括 ok、retryable_error、degraded、fatal。主循环处理有上限的重试与重复调用，记录参数、耗时与使用量。步数和累计用量在每轮开始前检查，可能在单次调用中超出预设总量，不是绝对费用上限。

上下文窗口保留最近若干步工具结果，更早结果改为摘要桩，维持调用/结果配对。原始任务、工具定义和其它消息仍占上下文；不能据此声称整个 prompt 恒定或任意任务都省固定比例 Token。

任务发起方可指定单篇锚定或最多六篇的论文集合。执行器校验问答、比较、方案和代码工具的论文参数，拒绝越界调用；省略参数时继承集合。两路召回共享过滤条件，重排和生成前复核证据归属，轨迹保存实际范围。详见 [任务论文范围](task-scope.md)。批量入库与代码执行通过共享确认钩子；确认不等于对代码安全性的证明。

## RAG：同一语料，两路召回

文档先解析并按页/章节分块，嵌入后写入 Chroma，元数据保留 paper_id、chunk_id、章节和页码。查询时，必要的多轮改写产生检索问题，再并行概念上的两路召回：

1. 查询向量搜索语义相近的块。
2. BM25 对同一文档文本按词项相关性排序。
3. RRF 按名次合并去重，不直接相加两路原始分数。
4. 重排模型在已召回候选内选择靠前证据，无法恢复两路都没召回的块。
5. 原问题和最终证据用于生成回答，附可展开来源。

两路执行的实际顺序与回退在 `rag/qa.py`；这里的“两路”不承诺同时发起网络请求。向量故障可在有关键词结果时回退；重排故障可回退融合排名并提示。相关性阈值不是事实证明或彻底消除幻觉的保证。

## 字段绑定：定位与支持分开

先读取已生成的 experiment.json，再从本文全部已索引块寻找候选依据。每项字段保留原始值、规范化值、引用集、引用状态与支持状态。

校验范围包括论文归属、块 ID、索引版本、文本摘要、页码/章节、精确字符区间。自动候选保持 unverified；本地声明式人工复核必须匹配当前事实摘要才可沿用。事实、原文或引用集变化会停用旧确认。

比较输出有篇数、每字段条数、片段和总长度预算，省略单独标记。条件不足时 numeric_comparison.ranking_allowed=false，模型提示和界面说明不据裸值排名；当前没有最终回答的自动语义证明或硬拦截器。

## 存储与恢复

文献/会话使用 SQLite，向量与文本使用 Chroma，抽取/报告/计划为本地文件，任务轨迹为 JSONL。流水线续跑依据账本状态与已有产物，尚未配置 LangGraph checkpointer；任务历史回读也不等于在中断点恢复模型执行。

实验结构/报告使用内容与契约 manifest，索引使用文本、分块与嵌入配置指纹。旧全文不会仅因模式相同而复用；写入失败尝试回滚，问答检查已登记的源文本与嵌入版本。详见 [资料与产物版本](content-versions.md)。

Chroma 首次初始化用进程内锁避免并发请求读到半初始化共享对象，常规检索不持有该锁。这不提供跨进程读写快照或完整事务隔离。

同一路径的块覆盖和读取另用进程内重入锁，避免读到本进程更新/回滚中的块；不能据此推断整条问答链或跨进程任务具备事务快照。

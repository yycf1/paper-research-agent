# M25 开发笔记 · 真实数据集复现：五轮 Agent 协作的完整记录

M25 没有新增产品代码——它的交付物是一个**真实验证准确率**和一份完整可
审计的复现轨迹。目标：把简历措辞从"合成数据原型"做实为"在真实数据集上
跑通方案管线"。

## 1. 数据资产

论文（Graph-Based Reasoning over Heterogeneous External Knowledge for
CommonsenseQA）用 CommonsenseQA，官方 S3 公开下载：train_rand_split.jsonl
（9,741 题）+ dev_rand_split.jsonl（1,221 题；注意不是 valid_rand_split，
那个 key 不存在）。落 `data/repro/<id>/workspace/data_*.jsonl`——放进
工作区是刻意的：agent 的 run_code 以工作区为 cwd，代码直接相对路径读取，
不需要任何联网或沙箱豁免。

## 2. 五轮 Agent 任务：真实的人机协作记录

| 轮次 | 结果 |
|---|---|
| ① 升级原型 | 14 步打满熔断。亮点：幻觉 source_id 被 fatal 打回后自我纠正；用 _peek 脚本探查数据格式；正确写出 run_real.py。卡点：180s 超时。 |
| ② 续任务（未锚定 source_id） | **漂移**：模型自行检索、入库了优化器论文（Evolution Strategies），把代码写进了别人的工作区。人工清理：删误入库论文 + 删误建工作区。 |
| ③ 续任务（锚定 source_id） | 用 5 个 peek 脚本读完 363 行代码，精确定位根因：**中心差分数值梯度 × 12,865 参数 ≈ 2,470 万次前向**。写出解析梯度版，步数耗尽未执行。 |
| ④ 直接执行 | 150s"超时"且 stdout 为空——**假象**：stdout 块缓冲，超时杀进程丢输出；真实卡点是文件仍是旧版（③的写入没生效）。 |
| ⑤ 带实测预算重写 | 开发者实测给数据（convert 5s / 前向 0.07s每批 / num_grad(64)>240s），Agent 一次改对：解析反向传播、修数据解析 bug（choices 在 question 键下）、MLP-only 训练——**0.8s 跑完，300 倍加速**；首版 20.7% 卡随机，自诊断 LR 过弱 + 无归一化，写好 He init/归一化版。 |
| ⑥ 只跑不改 | **最终：全量 1,221 题验证准确率 22.03%（269/1221），exit 0，0.9s**。 |

## 3. 诚实评估：22% 意味着什么

- **管线是真实的**：真实数据 → 词表/建图 → 拓扑重排 → GCN → 注意力 →
  MLP 训练，loss 1.97→1.53 正常下降，准确率稳定略高于随机（20%）；
- **差距来源明确**：论文 79.3% 依赖 XLNet 预训练编码器 + ConceptNet/Wikipedia
  全库知识（复现方案"复现资产评估"一节早已写明这些不可得）。最小原型冻结
  嵌入与 GCN、只训练 8,965 个 MLP 参数，本来就定位为"验证管线"，不追指标；
- 简历措辞据此收敛：**"在真实 CommonsenseQA 数据上跑通方案的图推理管线
  并测得真实准确率（最小原型口径），复现资产缺口（无官方代码/知识源依赖）
  已在方案中评估"**——比虚报一个接近论文的数字可信得多。

## 4. 三条工程教训（比数字更值钱）

1. **续任务必须锚定上下文**：跨任务无记忆 + 任务描述未点名 source_id →
   模型自主"开辟新课题"（检索→入库→在别人工作区写代码）。护栏拦住了
   越界执行，拦不住"合法但跑偏"——锚定信息必须进任务文本；
2. **超时 + 空 stdout 可能是缓冲假象**：subprocess 块缓冲下，超时杀进程
   会丢掉全部已打印内容。诊断先验证"真的没输出"还是"输出没刷出来"
   （print flush / python -u）；
3. **给模型实测数字比自己猜强**：第⑤轮带上 convert/前向/num_grad 的
   实测耗时后，一次改对——模糊的"优化一下"换了三轮，精确的预算一句话。

# M18 开发笔记 · 一键处理透明化

用户实测反馈：一键处理「过程完全不透明、呈现效果不好、不知道它有什么作用」。
三条批评对应三个根因，本里程碑逐一对治——顺带挖出一个被旧 UI 埋掉的
**下载失败后永远无法重试**的存量 bug。

## 1. 诊断：不透明是架构性的，不是缺个 spinner

- **过程黑箱**：`process_paper` 把阶段记录攒在内存 `out["steps"]` 里，
  **整个跑完才随返回值出现**。而 analyze 阶段捆着两个 LLM 调用（实验结构 +
  精读报告），动辄一两分钟——期间前端轮询 `job.result.steps` 永远是空，
  只能转圈，最后四步「哗」一下全出来；
- **呈现差**：处理完没有任何「你得到了什么」的收尾，产物页签静默出现；
- **价值不明**：价值链（全文 → 报告/实验结构 → **入知识库后可对本文问答**）
  从未在界面上表达。

## 2. 后端：阶段结构化 + job.result 原地更新

关键洞察：`jobs.submit` 传给任务函数的 `result` 参数**就是轮询端点返回的
同一个 dict**——任务线程里原地写入，GET /api/jobs/{id} 立即可见。不需要
新的进度基础设施，一行 `result["stages"] = [...]` 就把黑箱打开了。

- 阶段从 4 个拆成 **5 个**：download / parse / **experiment / report**（拆开）/ index，
  各带 `status: running|ok|skipped|failed`、detail、duration_ms；
- `process_paper(..., progress=stages回调)`：每次阶段状态变化通知，
  API 层回调里做快照写入（`[dict(s) for s in stages]`，避免竞态）；
- **产物级复用**：experiment.json 写盘时机提前到提取完成即刻；重试时
  mtime 未过期则复用（detail 注明「复用上次提取结果」）——报告生成失败
  重试不再重复花这份 token；
- **存量 bug 修复**：阶段门槛只认 `discovered`，`download_failed` 的论文
  重试时五个阶段全部「跳过」然后原样报错，永远无法重试。旧 UI 把步骤攒到
  最后显示，这个坑无从察觉；透明化第一天真机验证就把它暴露了。修复：
  下载门槛 `status in ("discovered", "download_failed")`。

## 3. 前端：五阶段时间线 + 完成/失败卡 + 针对本文提问

- **时间线**：前端维护 5 个阶段的全量骨架（`CANON_STAGES`），后端数据按
  key 填充——未开始的阶段显示「等待中/未执行」，用户从按下按钮那一刻就
  知道全程有哪几步、现在到哪步（running 行转 spinner）；
- **完成卡 / 失败卡**：done 后按结果分叉——成功（含全部跳过的「产物已就绪」
  变体）给绿色卡 + 指向提问/复现方案；失败给红色卡 + 失败阶段与原因 +
  「已完成的部分都保留了，重试会跳过已完成阶段」的预期管理；
- **针对本文提问**：详情页内联 RAG 问答框（`api.ask(q, paper_id)` 本就
  存在，从未有入口），处理完的论文当场验证知识库效果——这是「处理有什么
  用」最直接的回答；
- 按钮文案带状态（一键处理/处理中/重新处理）+ tooltip 全链说明；空状态
  改为编号步骤说明；精读报告换大阅读区；EuropePMC 摘要的 HTML 标签剥除。

## 4. 验证与踩坑

- `tests/test_process_stages.py` 5 个用例：报告失败停在 parsed、重试复用
  experiment.json、progress 回调时序（每阶段先 running 再落定）、无 PDF
  失败、**download_failed 重试**（回归）；`test_api.py` 增加「运行中轮询
  可见 running 阶段」的透明化回归；`tests/test_download.py` 4 个用例
  （落地页二跳、无 meta 失败、非 HTML 不触发、真 PDF 直通）。共 30 用例全绿。
- 真机：EuropePMC PDF 端点对浏览器 UA 也 403（Cloudflare 拦截，与 arXiv
  被墙同类，属网络环境问题）——下载失败路径反而成了最好的展示素材；
  已分析论文重处理 → 四阶段跳过 + 索引完成 + 完成卡；提问框实测返回真实
  RAG 答案与页码出处。
- **落地页回退（用户实测触发）**：用户处理一篇 AAAI 论文失败——OpenAlex
  把 DOI 落地页存成了 pdf_url，下载拿到的是 HTML 文章页。修复：download
  阶段对 HTML 响应解析标准元数据 `citation_pdf_url`（OJS/多数出版社都有）
  插队重试。真机复测该论文：DOI→HTML→PDF 二跳下载 558KB，五阶段全过
  （parse 58558 字符 / experiment 86s / report 101s / index 24 块）。
- IAB 浏览器本日 `cua.click` 对详情页按钮也不生效（老坑的新变种），改
  `evaluate(() => button.click())` 触发；截图帧偶发滞后，以 DOM 快照 +
  evaluate 取证为准。

# M20 开发笔记 · 双主题与全站去拥挤

用户反馈：UI 不好看、功能显示拥挤、全站只有黑色主题——要求至少黑/白两套
主题并放进设置。三件事一根因：**CSS 里散落着几十处硬编码色值**（rgba 写死的
强调色/状态色），不收拢就没有主题可言。

## 1. 全量 token 化：一套规则，两套变量

把 index.css 推倒重写（约 600 行 → 结构化重组），所有颜色收敛为语义 token：

- 表面：`--bg / --panel / --panel-2 / --border / --text / --muted`；
- 强调：`--accent / --accent-2 / --accent-deep / --accent-soft / --accent-border`；
- 语义三件套 ×5（green/red/yellow/purple/muted）：文字 + 软底 + 描边——
  状态徽章、四态 badge、完成/失败卡、测试连接结果全部改引 token；
- 杂项：`--mask`（弹窗遮罩）、`--subtle`（极淡底）、`--scroll*`（滚动条）、
  `--shadow`。

组件规则里不再出现任何字面颜色。`:root` 即暗色默认，`[data-theme="light"]`
只覆盖变量值——切主题 = 改一个 DOM attribute，组件零改动。

## 2. 主题 plumbing：三层持久化

- `theme.ts`：`applyTheme/initTheme/currentTheme`；`main.tsx` 在 **render 之前**
  同步读 localStorage 应用主题（防首帧闪烁）；
- localStorage 是即时层（点选卡片立刻生效 + 刷新保持）；
- `data/settings.json` 是持久层（`PUT /api/settings` 带 `theme` 字段，
  pydantic `pattern="^(dark|light)$"` 拦非法值；GET 回传）。新设备
  localStorage 为空时跟随后端——设置弹窗加载时补齐；
- 设置弹窗顶部「外观主题」双卡片（深色/浅色 + 迷你色板预览 + 一句话描述）。

## 3. 去拥挤：间距全面放宽

拥挤主要来自 M17 后功能增多但间距没跟上：顶栏 54→58px；检索区/过滤区/
分组行 padding 与 gap 各加 2~4px；表格单元格 9→12px；详情面板 20→24/28px、
标题 18→19px；聊天区 log/input 24→28px、气泡 10→12px 内边距；按钮统一加高
1~2px。配套修了两个换行 bug：状态徽章与表头/数字列补 `white-space: nowrap`
（「已发现」「摘要」不再折行）。

## 4. 验证

- 测试：`test_api_settings.py` 扩到 8 用例（主题落盘回读、非法值 422 且不
  破坏原值）；API 回归 29 个全绿；
- 浏览器实测：设置卡片切换即时生效（暗→浅→暗往返）；保存后刷新仍保持
  （localStorage）；新设备跟随后端的分支由 SettingsModal 加载逻辑覆盖；
  浅色下文献库/设置弹窗/助手页三处截图验收，无残留暗色块、无对比度问题。

## 5. 后续
